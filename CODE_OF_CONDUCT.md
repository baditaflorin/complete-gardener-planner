# Code of Conduct

## Our Pledge

We pledge to make participation in this project harassment-free for everyone.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent while being clear about impact.
- Keep feedback focused on the work.
- Help newcomers understand the static-first architecture before proposing server-heavy changes.

## Unacceptable Behavior

Harassment, abuse, personal attacks, doxxing, and discriminatory language are not acceptable.

## Enforcement

Maintainers may remove comments, close issues, or block participants who violate this code of conduct.

Report issues through:

https://github.com/baditaflorin/complete-gardener-planner/security
